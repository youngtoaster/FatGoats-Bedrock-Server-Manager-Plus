Questions

Frequently asked questions

How does the 1-click addon auto-installer work?

When a .mcaddon, .mcpack, or .zip file is dropped into the panel, the manager decompresses the archive, inspects manifest.json to determine whether components are behavior packs or resource packs, copies them to their respective directories in bds/behavior_packs/ and bds/resource_packs/, and registers their UUID headers directly into world_behavior_packs.json in the active world directory.

Will updating the manager delete Minecraft worlds or configuration files?

No. Updates execute clean Git fast-forward pulls and rebuild the client interface. User directories including worlds/, data/db/, server.properties, allowlist.json, and permissions.json are strictly preserved.

How do instant heal and food saturation commands execute?

The manager writes instant amplifier-255 potion effects directly to the unbuffered standard input pipe of bedrock_server.exe targeting the player's username. The effect takes effect in under 20 milliseconds without restarting the process.

Can players on Xbox, PlayStation, or Switch join without port forwarding?

Yes. Built-in Playit tunneling provides an encrypted outbound connection that bypasses CGNAT without router configuration. Built-in MCXboxBroadcast logs into a Microsoft account to advertise the server directly to your Xbox Friends list so console players can connect from their Friends tab.

How are backups protected against database corruption during gameplay?

The manager implements Mojang's official LevelDB backup specification: issuing save hold, querying save query until chunk files are safely locked and flushed to disk, copying the frozen files, and issuing save resume before compressing the snapshot to a zip archive.
