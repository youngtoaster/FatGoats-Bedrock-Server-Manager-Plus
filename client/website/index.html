Frequently Asked Questions

Everything You Need to Know

How does console crossplay work without port forwarding? +

FatGoats BSM+ integrates an automated Xbox Live bot that connects to the Xbox network and friends your players. Console Minecraft clients (Xbox, PlayStation, Nintendo Switch) automatically discover the server through the native Friends tab without requiring DNS redirects or port alterations.

How do Instant Healing and Instant Food heal work? +

In Minecraft Bedrock Edition, the server uses native /effect <player> heal 1 255 true and /effect <player> saturation 1 255 true commands. Amplifier 255 instantly replenishes health points and saturation without displaying floating potion bubbles.

Can I import my existing Minecraft Bedrock worlds? +

Yes! Simply drag and drop any .mcworld or .zip file into the World Management view. The manager inspects the internal NBT headers, extracts the LevelDB chunks, and safely registers the world for instant play.

How are banned players kept from reconnecting? +

While vanilla BDS lacks a persistent ban system, FatGoats BSM+ acts as a high-speed process wrapper. The moment a client attempts connection, the manager validates their Gamertag and XUID against SQLite and banned-players.json, issuing an immediate kick before any world chunks load.
